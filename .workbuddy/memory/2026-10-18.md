## 16:50 头像选择器「点头像就抖」修复

**现象**：用户截图——点/悬停卡牌头像时整块内容抖动，右侧出现一条细滚动条。

**根因**（量出来的）：`.ap__cell` 46px（42 + 2px border×2），hover `scale(1.12)` → 51.5px，而 `.ap__grid` 只留 2px padding 且 `overflow-y:auto`，放大瞬间撑出滚动区 → 全局自定义滚动条（`::-webkit-scrollbar` 10px）闪现 → grid clientWidth 476→466，整行列位移 5px → 鼠标脱离 hover → 缩小 → 滚动条消失 → 无限循环。

**改法**（只动 `AvatarPicker.vue`）
- grid：列宽 42→46 与 cell 外框同宽，gap 10→8，padding 2→6（吸收 hover 放大的 1.8px/边），**去掉 max-height + overflow-y**（不再内部滚）。
- cell：`box-sizing:border-box; width/height:46px`，hover 1.12→1.08，`outline:none` + `:focus-visible` 保留键盘焦点环。
- 弹窗限高（新增全局 style，`class="ap"` 落在 `.el-dialog__wrapper` 上）：`.el-dialog` flex 列 + `max-height: calc(100vh - 15vh - 62px)`，header/footer `flex:none`，body `overflow-y:auto; scrollbar-gutter: stable both-edges`。原来 71 张卡时弹窗 745px 超出视口 → wrapper 整层滚 → 居中弹窗被推偏。
- 关键：`.ap .el-dialog__wrapper` 这种写法**不生效**（.ap 就在 wrapper 自己身上），必须 `.el-dialog__wrapper.ap`，且 scoped 选择器对根元素的后代无效 → 写在非 scoped 的 `<style>` 块里。

**验证**（agent-browser 量测）
- 4/5 张卡：hover 真实触发（cell 46→49.7），grid cw/sw 466 不变、sh 58 不变、相邻卡 x 完全不动。
- 71 张卡：body 内滚（内容 768 / 可视 311），弹窗高 428、上下位置固定，点击卡前后 x/y 完全一致（634/447），wrapper 不滚、页面 docW=winW=1280。
- 弹窗左右各 380px 严格居中；lint 无错；build 通过。
