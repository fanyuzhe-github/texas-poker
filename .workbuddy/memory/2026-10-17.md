## 修复：「去抽卡」后牌桌没重置

**现象**：结算抽屉点「去抽卡」，抽完卡关掉数据中心，牌桌还摆着上一局的筹码和战绩，看着像没结算（用户截图反馈）。

**原因**：`openCardDrawer()` 只做了 `drawer = false` + 320ms 后 `openModule('cards')`，从头到尾没调 `resetBoard()`——「关闭」「再来一局」才会收桌子。

**改法**（`GameDetail.vue`）
```js
this.drawer = false;
window.setTimeout(() => {
  if (!this.settling) return;   // 这 320ms 内点了再来一局/关闭，已经重置过
  this.resetBoard();
  this.openModule("cards");
}, 320);
```
`settling` 是「已结算未收桌」的标记：点去抽卡时还是 true → 收桌子；点了再来一局/关闭时已被 `resetBoard()` 置 false → 不重复清、也不弹卡牌层盖住新局。选人标签保留，抽完卡点「开局选址」即可。

**验证**（agent-browser，1440×900）
- 正常路径：结算 → 去抽卡 → stage 落在卡牌 Tab，`seats=0 / isPlaying=false / settling=false / selects=6`；Esc 返回是「还没有开局」空态，今日榜照常。
- 竞态路径：`openCardDrawer()` 后立刻 `playAgain()` → 900ms 后 `stage=false, seats=6, isPlaying=true`，新局没被清掉、卡牌层也没弹。
- lint 无错、build 通过（dist 已重建）。
