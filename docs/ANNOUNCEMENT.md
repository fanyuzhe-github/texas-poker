# ♠ 德州扑克结算系统 · 全新升级上线

网址：<https://fanyuzhe-github.github.io/texas-poker/>

兄弟们，咱们的记账网页做了一次大换血。以前它只会算账，现在它会记账、会排名、会颁奖，还会发牌（卡）。下面说清楚：哪些地方修好了，哪些是新增的。

## 一、这次修好了什么

| 变化 | 以前 | 现在 |
| --- | --- | --- |
| 手机上能用 | 手机上表格挤成一团，要左右拖 | 座位表、玩家管理在窄屏直接换成卡片列表；浏览器「添加到主屏幕」，点开就是全屏，跟 App 一模一样 |
| 数据不怕丢 | 只存在本机浏览器里，清缓存就全没 | 设置里填一次 GitHub token，之后**自动备份**；换电脑、换手机一键恢复 |
| 老账不再算错 | 流水只留最近 200 局，第 201 局起赛季积分、纪录、勋章全部少算 | 改成按体积保留（约 2000 局），装不下时才砍最老的几局，并且明确提示 |
| 删局不留幽灵 | 删掉一局后，段位、纪录、勋章还按那局算 | 删局 / 清空流水会按剩余对局**重新重放一遍**，所有派生数据一起重算 |
| 一人多号 | 多个小号各自为战，算总账靠手加 | 主账号下挂子账号，总榜自动汇总，不重复计分；主账号不再上桌，只做汇总 |

## 二、新增亮点

**1. 段位系统（12 档）**
从「人形ATM」一路打到「赌神下凡」，中间还有慈善赌王、资深韭菜、奶茶富翁、割韭狂魔……每一档都配一句专属吐槽。座位上直接显示当前段位，鼠标悬停看吐槽。

**2. 记录榜（15 项，分三组）**
- 高光时刻 6 项：单局最高积分 · 碾压王 · 赛季最高 · 最高连胜 · 最猛一波 · 最高胜率
- 至暗时刻 6 项：最多输光次数 · 最长连败 · 垫底王 · 当头一棒 · 高台跳水 · 长夜漫漫
- 韧性时刻 3 项：翻盘王 · 不死小强 · 连败终结者

至暗那组不是把赢的纪录反过来说一遍，每一项都有具体画面：垫底是全场最差、当头一棒是连胜被终结那局亏最多、高台跳水是单日盘中最高到收盘的落差、长夜漫漫是输光后熬了最多局才翻身。

**3. 勋章墙（28 枚）**
荣誉勋章 / 连胜勋章 / 黑勋章三类，3 连胜到 10 连胜各有各的章，输了也留个名。每枚章都记着解锁的具体时刻。

**4. 抽卡收藏（71 张卡）**
打破纪录、点亮勋章会发奖券 —— 单抽 3 券，十连 21 券（十连更划算）。当天冠军每天还能免费单抽一次。抽到的卡可以直接设成自己的头像，1★ 到 5★ 外环颜色不同。

**5. 今日结算领奖台 + 数据看板**
每局结算完有亚军 / 冠军 / 季军上台，胜负盈亏一张条看完；数据看板里有资金曲线等图表；赛季榜按春 / 夏 / 秋 / 冬分季（冬季跨年），翻页看历史赛季。

**6. 结算更省事**
筹码用计算器一键数，提交前先验零和，数错了当场拦下；转账方案自动生成 —— 打开「人道模式」，让输得多的先付清，少跑几趟。

## 三、三步上手

1. 打开网址
2. 点「开局选座」，选人 —— 名册是空的就直接敲名字回车，新玩家自动入库
3. 填上各自剩余筹码 → 点「结算本局」→ 看领奖台、领奖券

手机上建议顺手「添加到主屏幕」（浏览器菜单里），之后点桌面图标就能开，全屏无地址栏。

## 四、关于数据

所有数据存在你自己这儿：本机浏览器 + 你自己名下的 GitHub 备份，不经过任何中间服务器。云备份用的是你自己的 token（只勾 gists 权限即可），随时可以断开或清空。
