今日结算

领奖台 + 数据看板 + 赛季榜

每局结算完亚军 / 冠军 / 季军上台，盈亏一张条看完；看板里有资金曲线等图表；赛季榜按春 / 夏 / 秋 / 冬分季（冬季跨年），能翻页看历史赛季。

结算

数筹码、转账一步到位

筹码用计算器一键数，提交前先验零和，数错了当场拦下；转账方案自动生成，打开「人道模式」让输得多的先付清，少跑几趟。

三步上手

  1. 打开网址（收藏一下，或者直接加到手机桌面）
  2. 点「开局选座」选人 —— 名册是空的就直接敲名字回车，新玩家自动入库
  3. 填各人剩余筹码 → 点「结算本局」 → 看领奖台、领奖券

关于数据

所有数据都在你自己手上：本机浏览器 + 你自己名下的 GitHub 备份，不经过任何中间服务器。 云备份用你自己的 token（只勾 gists 权限即可），随时可以断开，也可以一键清空云端存档。
